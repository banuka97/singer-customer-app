# Security and Data Handling

This application is designed as a client-side decision-support tool.

## Customer data

Uploaded transaction files are parsed in the browser. The application is not designed to upload or persist the source Excel file on the GitHub Pages site.

Operators should only process customer information they are authorized to use and should follow the organization's applicable privacy, retention, and access-control requirements.

## Access control

GitHub Pages serves the static application publicly unless access control is added through a different hosting architecture. A client-side password or hidden link must not be treated as authentication.

## Customer-facing messaging

Internal stock/availability indicators are intentionally excluded from WhatsApp and SMS message generation.

## Reporting issues

Do not post customer records, phone numbers, transaction files, or other confidential information in public GitHub issues.
