Singer Customer Next‑Product Recommendation App

Upload transaction history → identify customer opportunities → map recommendations to Singer products → export customer recommendations. Singer price/offer data refreshes automatically from the public Singer catalogue via GitHub Actions.

1. Upload Customer Transaction File

Excel file (.xlsx) required Expected fields: ORDER_NO, PRODUCT, PRODUCT DESCRIPTION, DATE OF SALE, UNITS, CUSTOMER ID NUMBER, CUSTOMER NAME, PHONE / MOBILE NUMBER (optional but recommended)

2. Export Recommendations

Export the completed customer-wise recommendation analysis to Excel. Includes customer phone/mobile number, three distinct product recommendations, three-language customer messages (English / Sinhala / Tamil), WhatsApp click-to-chat and normal SMS options when a valid number is available. Product prices and offers come from the latest catalogue.json generated by the GitHub scheduled updater.
Privacy: the uploaded Excel file is processed in this browser and is not uploaded or stored by this page. Internal stock status is for sales-team use only and is never included in customer-facing WhatsApp/SMS messages.
Singer catalogue: loading saved snapshot…
On mobile, WhatsApp opens a pre-filled message and SMS opens the phone's normal messaging app; you still tap Send. The GitHub Action refreshes Singer catalogue data hourly. The Refresh Live Singer Data button reloads the latest generated catalogue.json. Offers and prices can change.

Recommendation Diversity Rule

Primary + Alternative 1 + Alternative 2 are designed to be different products. The engine avoids repeating the same SKU/product and prioritizes different product categories. When a customer has already purchased most new categories, additional catalogue products are used to preserve product-level diversity.
